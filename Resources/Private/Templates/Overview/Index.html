Passed to f:be.infobox as ".value" (the plain int), not as the enum case itself: on v13.4 InfoboxViewHelper registers "state" as type "int", so handing it the enum object makes Fluid's argument validation throw (InvalidArgumentException 1256475113) before render() is ever reached. Only v14 widened that argument to "mixed" and accepts a ContextualFeedbackSeverity. The int is valid on both. InfoboxViewHelper::STATE_* would work too, but those constants are deprecated since v14 and go away in v15.
