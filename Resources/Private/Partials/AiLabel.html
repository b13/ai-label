Renders the AI origin marker for the current content record (or, if a FAL "file" argument is passed, for that file) - nothing renders unless the record/file is actually flagged. Arguments: - file (optional): a FAL file reference, e.g. arguments="{file: image}" - data (optional, defaults to the record already in scope): the tt_content (or other applicable table) row, e.g. arguments="{data: someRecord}" - variant (optional, default "black"): one of "black", "black_transparent", "white", "white_transparent" - selects which of the bundled icon sets to use.
