Overrides EXT:fluid_styled_content's own Media/Rendering/Image partial, so that a flagged image can carry the AI marker on the image itself rather than only on the surrounding content element. Unlike DropIn/After/All.html - an extension point Core ships intentionally empty - this overrides a partial that has real content, so the call below is a verbatim copy of Core's and has to be kept in sync when Core changes it. It is identical on v13.4 and v14; only the file name differs (Image.html vs Image.fluid.html), which is why this file exists twice. Nothing is wrapped unless the image marker mode is "overlay" AND the image is actually flagged - in every other case this renders byte-for-byte what Core would have rendered, including in "baked" mode, where the marker is already in the pixels. {renderedImage -> f:format.raw()} {renderedImage -> f:format.raw()}
